A fork of the snarktank/ai-dev-tasks prompt templates: `create-prd.md`, `generate-tasks.md`, `process-task-list.md`, and an added `initiate-code-review.md` guide the AI through clarifying questions, a PRD, a parent/sub-task breakdown, and one-task-at-a-time implementation with checkpoints. It is in active use as a working directory, not just a template copy - `tasks/` holds real PRDs and task lists generated for another project (html2godot), including a code-quality-infrastructure PRD driven through this same workflow.
